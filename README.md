# AI Commerce Intelligence Platform

End-to-End Machine Learning platform built using the Olist E-Commerce Dataset.

## Features

- Customer Segmentation
- Churn Prediction
- Customer Lifetime Value Prediction
- Fraud Detection
- Explainable AI
- Streamlit Dashboard

## Tech Stack

- Python
- Pandas
- Scikit-Learn
- XGBoost
- SHAP
- Streamlit
- Plotly

## Completed Modules

- Data Auditing
- Customer Feature Engineering
- Exploratory Data Analysis
- PCA Dimensionality Reduction
- Customer Segmentation (KMeans)
- Customer Persona Generation
- Repeat Purchase Behavior Analysis
