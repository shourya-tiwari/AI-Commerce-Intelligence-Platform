# AI Commerce Intelligence Platform

End-to-End Machine Learning platform built using the Olist E-Commerce Dataset.

## Features

- Customer Segmentation
- Churn Prediction
- Customer Lifetime Value Prediction
- Fraud Detection
- Explainable AI
- Streamlit Dashboard

## Tech Stack

- Python
- Pandas
- Scikit-Learn
- XGBoost
- SHAP
- Streamlit
- Plotly
